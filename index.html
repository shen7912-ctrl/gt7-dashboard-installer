安裝流程
1. ESP32 用 USB 接電腦。
2. 使用 Chrome 或 Edge 開啟此頁。
3. 你的裝置請選 ILI9341。
4. 按 Connect & Install，選擇 USB Serial。
5. 第一次安裝請清除裝置後寫入。
6. 完成後重新設定 Wi‑Fi，再進 GT7 測試。
